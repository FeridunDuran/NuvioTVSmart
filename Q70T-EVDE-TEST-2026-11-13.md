## HLS karşılaştırma kumandaları — ancak evde, sonraki kaynak açılmadan önce

Console/WebInspector'da bir profil seç, ardından mevcut videodan geri çıkıp aynı kaynağı yeniden aç. Bu değişken kalıcı ayar değildir; restart veya delete ile sıfırlanır. Bir deneyde yalnız bir değişkeni değiştir.

```js
// Önceki50sn buffer; auto engine.
window.__NUVIO_Q70T_PLAYBACK__ = { bufferProfile: "original", hlsEngine: "auto" };
// Yeni varsayılan30sn.
window.__NUVIO_Q70T_PLAYBACK__ = { bufferProfile: "balanced", hlsEngine: "auto" };
// Daha küçük tampon15sn; dalgalı ağda kötüleşebilir.
window.__NUVIO_Q70T_PLAYBACK__ = { bufferProfile: "memory", hlsEngine: "auto" };
// Motor A/B: önce buffer'ı sabit tut.
window.__NUVIO_Q70T_PLAYBACK__ = { bufferProfile: "original", hlsEngine: "avplay" };
window.__NUVIO_Q70T_PLAYBACK__ = { bufferProfile: "original", hlsEngine: "hls.js" };
// Varsayılanlara dönüş:30sn + bilinenUHD için AVPlay-first.
delete window.__NUVIO_Q70T_PLAYBACK__;
```

`hlsEngine` sıra tercihidir; zorunlu engine başarısı veya fallback yasağı değildir. Oynatıcıda forceEngine varsa explicit seçim önceliği korunur. Buffer profili AVPlay'in native buffer'ını değiştirmez. Değişkenleri arka arkaya çalıştırmak test değildir: her satır ayrı deney içindir.

- Loglara authheader, apiKey, tam signedmediaURL, addon konfigürasyonURL'si koyma. Kaynakları deneme koduyla etiketle; codec/container/height/bitrate bilgisi yeterli.
